# 機能ドキュメント: ワークフロー変数

## 概要

ワークフロー変数機能は、ワークフロー内のステップ間で動的にデータを共有するための仕組みです。あるステップの実行結果（例: シェルコマンドの標準出力やPython関数の戻り値）を変数として保存し、後続のステップのパラメータとして利用することができます。

これにより、より複雑で連携性の高いワークフローを構築することが可能になります。

## 主な機能

1.  **出力の変数へのマッピング**:
    ワークフローの各ステップの実行結果を、指定した名前の変数に保存できます。

2.  **パラメータでの変数の参照**:
    後続のステップのパラメータ入力欄で、`{{ variables.変数名 }}` という形式のテンプレート構文を使い、保存された変数の値を参照できます。

## 使用方法

### 1. 出力変数の設定

ワークフローのステップ編集画面に、新たに追加された以下の項目を設定します。

-   **出力変数名**:
    -   このステップの実行結果を保存するための変数名を指定します。（例: `step1_result`, `file_content`など）
    -   この名前はワークフロー内で一意であることが推奨されます。

-   **キャプチャ対象**:
    -   ステップの実行結果のうち、どの部分を変数として保存するかを選択します。
    -   **戻り値 (Pythonジョブ)**: Python関数の `return` で返された値。
    -   **標準出力 (シェルジョブ)**: シェルコマンドが標準出力に出力した内容。
    -   **標準エラー出力**: 標準エラー出力の内容。
    -   **終了コード**: プロセスの終了コード（成功時は `0`）。

### 2. 変数の利用

後続のステップで、パラメータを指定する任意のテキスト入力欄に、以下の形式で変数を埋め込みます。

```
{{ variables.変数名 }}
```

-   `変数名` の部分には、前のステップで「出力変数名」に指定した名前を入れます。

### 具体例

**ステップ1: ファイルの内容を読み込む**

-   **ジョブタイプ**: シェル
-   **コマンド**: `cat /path/to/my_file.txt`
-   **出力変数名**: `file_content`
-   **キャプチャ対象**: `標準出力 (シェルジョブ)`

**ステップ2: 読み込んだ内容をログに出力する**

-   **ジョブタイプ**: Python (タスク: `sample_tasks.echo`)
-   **パラメータ `message`**: `File content is: {{ variables.file_content }}`

このワークフローを実行すると、ステップ2は「File content is: (my_file.txtの内容)」というメッセージをログに出力します。

## 注意事項

-   変数の値がJSONオブジェクトやリストの場合でも、文字列としてパラメータに埋め込まれます。ただし、パラメータ欄に `{{ variables.変数名 }}` のみ入力されている場合は、元のデータ型（数値、真偽値など）のまま渡されます。
-   存在しない変数を参照した場合、ワークフローはそのステップの実行に失敗します。
